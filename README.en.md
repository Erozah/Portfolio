# Developer Portfolio - Erozah

Personal responsive portfolio website showcasing software development projects, technical skills, and engineering practices across Java, Spring Boot, JavaScript, and Python.

Built with modern web standards: semantic HTML5, modern CSS (CSS Grid, Flexbox, custom properties), and vanilla JavaScript without heavy third-party framework overhead.

---

## 🚀 Featured Projects

- **Spicetify Visualizer Engine**: 60 FPS real-time audio visualizer engine for Spotify (Canvas 2D, Web Audio API, Verlet physics).
- **WiFi Signal Tracker**: Live WiFi signal meter and radiofrequency Geiger counter tool (Python, Web Audio API, Canvas).
- **Dungeons & Dragons**: Turn-based RPG and board game engine written in Java (OOP, polymorphism, JUnit 5).
- **Square Games Platform**: REST API and web UI for turn-based board games featuring modular plugin design, JPA/JDBC persistence, and JWT RSA security.
- **CartSync**: Collaborative grocery lists API and real-time budget calculation engine (Hexagonal Architecture, Offline-First, Spring Boot).
- **Users Microservice**: Spring Boot service handling user identity management and verification.

---

## 🛠️ Tech Stack

- **Front-end**: Semantic HTML5, CSS3 (Custom Properties, Grid, Flexbox), JavaScript ES6+
- **Performance & Design**: Mobile-responsive layout, dark mode aesthetic, zero heavy dependencies

---

## 💻 Local Setup

The project runs natively without any build step:

```bash
# Option 1: Open the HTML entrypoint directly
xdg-open index.html

# Option 2: Run a lightweight local HTTP server
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
