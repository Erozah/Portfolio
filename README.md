# Portfolio Développeur - Erozah

Site web personnel responsive présentant mes projets, mes compétences techniques et mes réalisations en Java, Spring Boot, JavaScript et Python.

Conçu selon les standards du web moderne : HTML5 sémantique, CSS moderne (CSS Grid, Flexbox, variables CSS), et JavaScript vanilla sans framework externe lourd.

---

## 🚀 Projets Présentés

- **Spicetify Visualizer Engine** : Moteur de visualisation audio 60 FPS pour Spotify (Canvas 2D, Web Audio API, physique de Verlet).
- **Wifi Signal Tracker** : Outil d'analyse du signal Wi-Fi en temps réel avec retour audio type compteur Geiger (Python, Web Audio API, Canvas).
- **Donjons & Dragons** : Moteur de jeu de rôle et plateau au tour par tour en Java (POO, héritage, polymorphisme, JUnit 5).
- **Square Games Platform** : API REST et interface web de jeux de plateau avec architecture par plugins, double persistance JPA/JDBC et sécurité JWT RSA.
- **Users Microservice** : Service Spring Boot de gestion et validation d'identités utilisateurs.

---

## 🛠️ Stack Technique

- **Front-end** : HTML5 sémantique, CSS3 (Custom Properties, Grid, Flexbox), JavaScript ES6+
- **Performance & Design** : Responsive design, thème sombre optimisé, zéro dépendance externe lourde

## 💻 Démarrage Local

Le projet ne nécessite aucune étape de compilation. Vous pouvez l'ouvrir directement dans votre navigateur :

```bash
# Option 1 : Ouvrir le fichier HTML
xdg-open index.html

# Option 2 : Lancer un serveur local léger
python3 -m http.server 8000
```

Accessible ensuite sur [http://localhost:8000](http://localhost:8000).
